# EPIC 6 — Admin Interface Customization

## Feature 6.1 — Site Settings

### User Story

> As an administrator, I want to customize selected parts of the website so that the platform can adapt to different marketing campaigns and business needs.

Future settings should include:

```text
site_settings

theme_color
secondary_color
banner_text
banner_enabled
banner_image
discount_percentage
featured_category
homepage_message
```

### Tasks

* Create settings page.
* Create theme color inputs.
* Create banner text input.
* Create banner toggle.
* Create discount configuration input.
* Create preview panel.
* Create Save button.
* Create Reset button.
* Add unsaved changes state.
* Create mock settings service.
* Prepare API abstraction.
