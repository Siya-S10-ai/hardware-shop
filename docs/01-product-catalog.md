# EPIC 1 — Product Catalog & Categories

## Feature 1.1 — Product Catalog

### User Story

> As a customer, I want to browse available hardware and building products so that I can discover products relevant to my project.

### Tasks

* Create product TypeScript interface.
* Create realistic mock product dataset.
* Create product card component.
* Display product image placeholder.
* Display product name.
* Display category.
* Display price placeholder.
* Display stock status.
* Display engagement statistics where appropriate.
* Create responsive product grid.
* Create loading state.
* Create empty state.
* Create error state.
* Prepare product service abstraction for future API integration.
