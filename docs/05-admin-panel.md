# EPIC 5 — Admin Panel

## Feature 5.1 — Admin Dashboard

### User Story

> As an administrator, I want to see an overview of the platform so that I can understand what is happening in the system.

### Dashboard should display mock analytics such as:

* Total products
* Total users
* Total likes
* Total comments
* Total shares
* Most engaged products
* Recent activity
* Discount campaigns

### Tasks

* Create admin layout.
* Create sidebar navigation.
* Create dashboard cards.
* Create charts using mock data.
* Create recent activity table.
* Create responsive admin interface.
