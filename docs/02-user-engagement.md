# EPIC 2 — User Engagement

## Feature 2.1 — Like Products

### User Story

> As a customer, I want to like a product so that I can show interest in it and easily identify products I am interested in.

### Tasks

* Create reusable LikeButton component.
* Create liked/unliked states.
* Create optimistic UI mock behavior.
* Display like count.
* Prevent duplicate likes in the mock implementation.
* Prepare engagement service abstraction.

## Feature 2.2 — Comment on Products

### User Story

> As a customer, I want to comment on a product so that I can ask questions or share my thoughts.

### Tasks

* Create comment input.
* Create comment list.
* Create comment card.
* Create mock comment submission.
