# EPIC 8 — Targeted Discounts

## Feature 8.1 — Discount Management

### User Story

> As an administrator, I want to create discount codes for users based on their product interactions so that I can target highly interested customers.

### Tasks

* Create discount management page.
* Create discount code form.
* Create percentage discount input.
* Create expiry date input.
* Create eligible-user selection.
* Create eligible-product selection.
* Display active discounts.
* Display expired discounts.
* Display usage statistics.
* Create mock discount service.

## Feature 8.2 — Target User Selection

### User Story

> As an administrator, I want to identify users who interacted with specific products so that I can send targeted offers.

Example filters:

```text
Liked Product
Commented on Product
Shared Product
Multiple Interactions
Specific Product
Specific Category
Date Range
```

### Tasks

* Build filter UI.
* Build user results table.
* Build interaction summary.
* Add "Create Discount" action.
* Add mock targeting logic.
