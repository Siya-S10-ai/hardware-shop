# EPIC 4 — Authentication

## Feature 4.1 — Login

### User Story

> As a customer, I want to log into my account so that I can access personalized features.

### Tasks

* Create login page.
* Create email field.
* Create password field.
* Add validation.
* Add loading state.
* Add authentication error state.
* Add success state.
* Create mock authentication service.
* Prepare API contract for future backend.

---

## Feature 4.2 — Signup

### User Story

> As a new customer, I want to create an account so that I can interact with products and receive personalized offers.

### Tasks

* Create signup page.
* Create name field.
* Create email field.
* Create password field.
* Create password confirmation.
* Add validation.
* Add terms acceptance.
* Create mock signup service.
* Prepare backend integration interface.

---

## Feature 4.3 — Protected Routes

### User Story

> As an authenticated customer, I want protected areas of the application to remain accessible only to me so that my account remains secure.

### Tasks

* Create authentication context/state.
* Create protected route component.
* Create authenticated user model.
* Create login/logout state.
* Create mock session.
* Handle unauthenticated redirects.
