# EPIC 10 — UX States

Every major feature must account for:

### Loading

Example:

```text
Loading products...
```

### Empty

Example:

```text
No products found.
```

### Error

Example:

```text
Something went wrong.
Please try again.
```

### Success

Example:

```text
Product liked successfully.
```

### Unauthorized

Example:

```text
Please log in to continue.
```

### Token Error

Example:

```text
This link is invalid or has expired.
```

Do not build interfaces that only represent the "happy path."
